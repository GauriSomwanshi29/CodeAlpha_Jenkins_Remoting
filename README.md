## 📌 Project Overview

The **Jenkins Remoting Project** demonstrates how Jenkins can connect to remote build agents and execute jobs outside the Jenkins Controller.

This project uses Docker and Docker Compose to configure a Jenkins Controller and a separate Linux-based Remote Agent.

The Remote Agent connects to the Controller using a secure WebSocket connection and executes build jobs independently.

The main objective is to understand remote job execution, distributed build environments, agent configuration, and container-based isolation.

## 🎯 Project Objectives

- Configure a Jenkins Controller.
- Set up a remote Linux build agent.
- Establish communication using WebSocket.
- Execute Jenkins jobs on a remote agent.
- Verify remote execution through build logs.
- Understand container-based agent isolation.

## ⚙️ Installation & Setup

### 1. Prerequisites

Install the following tools:

- Docker Desktop
- Git
- GitHub Account
- Jenkins-compatible Java environment

### 2. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/CodeAlpha_Jenkins_Remoting.git
```

```bash
cd CodeAlpha_Jenkins_Remoting
```

### 3. Configure Environment Variable

Create a `.env` file in the project directory.

Add the following variable:

```env
JENKINS_AGENT_SECRET=YOUR_AGENT_SECRET
```

Replace `YOUR_AGENT_SECRET` with the actual secret generated by Jenkins for the configured agent.

**Security:** Never share or commit your actual Jenkins Agent Secret.

### 4. Start Docker Containers

Run:

```bash
docker compose up -d
```

Check running containers:

```bash
docker ps
```

### 5. Access Jenkins

Open the following address in your browser:

```text
http://localhost:8080
```

Configure Jenkins and create the remote node with the following settings:

| Configuration | Value |
|---|---|
| Node Name | remote-agent-2 |
| Executors | 1 |
| Remote Root Directory | /home/jenkins/agent |
| Label | linux-agent |
| Launch Method | Launch agent by connecting it to the controller |
| Connection | WebSocket |
